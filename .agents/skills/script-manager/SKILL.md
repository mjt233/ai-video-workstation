# 剧本资产管理

本技能负责 `design/{项目}/prompt/script/` 下**剧本文本资产**（大纲 + 分集）的读取与写入约定。

## 资产位置与结构

```
prompt/script/
├── outline.md             # 剧本大纲（Markdown）
└── episodes/
    ├── 1.md               # 第 1 集剧本正文（Markdown）
    ├── 2.md               # 第 2 集剧本正文
    └── ...                # 编号连续 1..N，无跳号
```

| 文件 | 内容 |
|------|------|
| `outline.md` | 剧本大纲：主题立意、人物弧线、分集梗概等（自由格式 Markdown） |
| `episodes/{n}.md` | 第 n 集完整剧本正文。初始模板含 `# 第n集` / `## 剧情梗概` / `## 正文` 结构，用户可自由改写 |

**基本定位：**

- 剧本由用户在资产管理器「剧本」节点**在线编辑维护**，是剧本内容的权威来源；Agent（或调用本技能的其他技能）**默认只读取**，仅在用户授意或确认后按下方「写入规则」修改
- 剧本与「集数分镜」**相互独立**：编号互不影响、各自增删；**不可假设「剧本第 n 集 = 分镜第 n 集」的数量一致**
- 剧本无对应 `assert/` 产物（纯文本原型，不参与生成流水线）

## 读取约定

- 直接用文件读取工具按路径读取，均为 UTF-8 Markdown 纯文本；路径以 `design/{项目}/prompt/script/...` 为基准（先确认当前操作的项目）
- **判断某集是否有剧本**：探测 `prompt/script/episodes/{集数}.md` 是否存在；`episodes/` 目录不存在表示整个项目还没有分集剧本
- **判断是否有大纲**：探测 `prompt/script/outline.md` 是否存在；不存在则跳过，不报错
- 剧本分集编号与集数分镜的集数编号**没有任何联动关系**，不可假设「剧本第 n 集 = 分镜第 n 集」的数量一致

## 写入规则

1. **用户授意时可写** — 用户明确要求修改/续写/润色剧本时，可直接用文件写入工具按路径写入 UTF-8 Markdown（如 `design/{项目}/prompt/script/episodes/2.md`）：
   - 写入前**必须先读取文件最新内容**（避免覆盖用户在资产管理器中的最新在线编辑）
   - **新建分集**取当前最大编号 + 1，保持编号连续与文件名约定（正整数 `.md`）；新建大纲写入 `outline.md`
2. **发现问题先确认** — 执行过程中（如设计分镜时的读取）发现剧本存在剧情矛盾、台词冲突、必要设定缺失等需要修改的情况，**不得直接改动**：应向用户说明问题所在与建议改法，**征得明确确认后**再修改，并告知用户可在资产管理器「剧本」节点查看结果
3. **其余情况不改动** — 未经授意不主动修改剧本；剧本缺失时不报错、不补建，按无剧本流程正常设计即可

## 与其他资产的关系

- 剧本正文中的对白是分镜 `script.json` 台词的**上游来源**：角色名与语义须与剧本一致；分镜资产本身由 `create-video-script` 技能的 Python 脚本写入（见该技能 [`04-script-tools.md`](../create-video-script/04-script-tools.md)）
- 「何时读取剧本」由调用方工作流决定（例如 `create-video-script`：设计某集分镜前**必须先读取该集剧本正文**，分镜的叙事节拍、事件顺序、对白内容以剧本为准）
