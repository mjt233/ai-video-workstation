# 视频剧本总览

## 前置设定

| 项目 | 内容 |
|------|------|
| **目标受众** | 职场成年人（25-35岁） |
| **情感基调** | 幽默搞笑，带一丝暖心 |
| **色彩基调** | 低饱和暖色调 |
| **美术风格** | 日本二维动画风格 |

## 剧情概要

周五下午17:55，打工人**小林**表面淡定地盯着屏幕，内心却已开启盛大的"下班倒计时"——偷偷关掉文档、收拾桌面、给绿萝浇水道别。每个动作都配着丰富的内心OS。就在她背起包准备胜利大逃亡时，老板的声音从背后响起……然而老板只是笑着说了一句**"周末愉快"**。小林愣了一秒，灿烂回了一句"您也是！"快步离去。

## 世界/时代背景

- **时代背景**：现代都市，典型的互联网/创意类公司办公环境
- **世界观规则**：贴近现实，无特殊设定
- **氛围关键词**：温暖的日常感、轻松幽默

## 角色总览

### 小林（主角）
- 女，27岁，表面文静乖巧，实则内心戏爆炸。在创意 agency 做了3年的设计师/文案。

### 老板（配角）
- 男，约40岁，看起来严肃但人不错。只在结尾出现一句台词。
