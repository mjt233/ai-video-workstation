# 创作工作流优化

## 工作流优化


### 视频工作流类型优化

工作流特性除了能声明是否支持导演台模式，还需要支持声明以下能力：

- 是否支持首尾帧模式
- 是否支持参考模式
    同时需要声明以下内容：
    - 支持什么类型的参考？（图片、视频、音频）
    - 每种参考类型最大支持多少数量
    - 最大支持的参考总数量
- 是否支持输入音频
- 视频最大输出时长（单位：秒，默认15）

### 工作流执行优化

优化工作流的执行接口，使其可以脱离具体的“场景”、“分镜”、“集数”等概念独立提交工作流，根据分镜、集数等概念读取对应数据的逻辑从工作流本体中抽离出来。


视频工作流调用参数interface统一规格（这里只列出视频的，其他类型的请自行设计）

```ts
/**
 * 资产分辨率
 */
interface Resolution {
  width: number

  height: number
}

/**
 * 统一视频工作流提交参数
 */
interface VideoWorkflowSubmitParam<T> {
  /**
   * 输出分辨率
   */
  resolution: Resolution

  /**
   * 视频帧率
   */
  fps?: number

  /**
   * 视频时长
   */
  duration: number

  /**
   * 视频生成提示词
   */
  prompt: string

  /**
   * 待设计
   */
  file?: 待定

  /**
   * 随机种子
   */
  seed?: number

  /**
   * 待设计
   */
  视频导演台数据?: 待定

  /**
   * 传递给具体工作流实现的额外参数
   */
  extraParams: T
}
```

### 工作流支持中断

工作流统一注册声明中需要补充中断的能力。目前所有的工作流都是基于ComfyUI Easy Bridge的接口，中断接口如下：

```
POST /api/tasks/:taskId/cancel
```

中断正在执行（`pending`）或排队中（`queued`）的任务。
- `queued` 任务：直接标记为失败，无需通知 ComfyUI。
- `pending` 任务：向 ComfyUI 发送 `/interrupt` 请求，再标记为失败。

**响应** `200`:

```json
{
  "task_id": "uuid-string",
  "status": "failed"
}
```

**错误响应**:

| 状态码 | code | 说明 |
|--------|------|------|
| `400` | `invalid_status` | 任务状态不是 `queued` 或 `pending`（如已完成或已失败） |
| `404` | `task_not_found` | 任务不存在 |


### 视频工作流类型优化

#### 首尾帧模式

复用导演台的参数，设定首帧出现位置为0，尾帧出现位置为末尾

#### 参考模式

额外传入有序音频、视频、图片的有序集合

新增基于ComfyUI Easy Bridge（bridge-client）的工作流实现
curl调用案例：
```bash
curl -X POST http://localhost:10721/api/workflows/minimax-h3-r2v/execute \
  -F 'params={ "duration": 1, "height": 1, "prompt": "a string value", "seed": 1, "width": 1 }' \
  -F "image_0=@/path/to/image_0.png" \
  -F "audio_0=@/path/to/audio_0.png" \
  -F "video_0=@/path/to/video_0.png"
```
动态文件参数：
image_${参考图序号}
audio_${参考音频序号}
video_${参考视频序号}
参考素材序号从0开始，不同类型的参考素材序号独立计算，必须保证从0开始步长按1递增。



## 资产画布 - 新增【生成视频】节点

资产画布新增【生成视频】节点，能脱离“集数”和“分镜”的概念独立调用工作流。

### 节点定义

- 支持图片、音频、视频类型的输入

### 节点配置组件

可以选择视频生成工作流，当选择的视频工作流支持导演台时，渲染一个视频导演台编辑界面。节点的所有图片和音频输入都自动添加到轨道中。如果输入的图片或音频断开了，需要自动在轨道中删除。节点元数据中需要记录导演台各个素材滑块的长度和位置。
当视频生成工作流支持“参考模式”时（后文会说明该视频工作流新增的特性），配置组件的布局与【生成图片】一致，顶部预览资源，下面文本域编写提示词。
