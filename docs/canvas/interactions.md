# 连线规则与画布交互

> 返回 [总览与定位](./README.md)

## 连线规则（`frontend/src/canvas/connection.ts`）

- 按**端口数据类型**判断兼容（ComfyUI 思路），v1 仅支持同类型：`image→image`、`text→text`；端口类型为**数组**（如 AI文本生成节点的 `['media','text']`、生成图片节点的 `['image','text']`）时任一匹配即可连接；`media` 输入口（生成视频）可接受任意来源（`canConnect`）。
- **生成图片的单一 `in` 口同时接受图片（参考图，可多路）与文本（外部提示词）**：连接后按来源节点输出类型自动归类，文本来源作为 `prompt` 取值（见 [node-types.md](./node-types.md)）。**文本输入在生成时限制为一个**（与生成视频节点同规则）：连接多个文本来源时不提交生成，编辑器红字 + `useCanvasNodeOps.generateNode` snackbar 拦截；连线本身允许建立（不做连线期拦截）。
- `canConnectNodes` = 类型兼容 + 不成环（`wouldCreateCycle` 反向可达性检测）+ 目标输入未满。
- 建立连线：从源节点输出手柄拖到目标节点输入手柄（`@connect` → `store.connect`）；连接失败静默忽略。
- **连线预览线高亮（拖拽中）**：从节点端点拖出连接线时，跟随鼠标的**预览线本身**高亮显示——统一使用**画布主题色 `#1976D2`**：线宽 **2px**（默认预览线为 1px 灰 `--vf-connection-path`）+ 同色 `drop-shadow` 光晕，视觉上明显区别于普通连线（普通连线 1px 灰、高亮关联连线 2px 实色）；拖拽结束（建立/落空释放）预览线连同高亮一起消失，无残留。**刻意不按输入/输出端点分色**：预览线的职责只是「正在连线」，起点端口类型已由鼠标下的端点与 Vue Flow 的端点指示器（`connectable` 端点圈）表达；且一条连线两端必为一输入一输出，「按起点分色」与「按落点分色」互为镜像，两种规则都说得通却都不直观，统一主题色消除该歧义（与运行态蓝高亮同色不冲突：预览线仅在拖拽中存在且始终连着鼠标，形态与「节点 Loading 时指向它的实线 + 流向箭头」判然有别）。实现：`AssetCanvas` 的 **`#connection-line` 插槽**（Vue Flow `FlowSlots` 类型化插槽，props = `ConnectionLineProps`）——`connectionPreview()` 用与默认预览线**逐参数一致**的 `getBezierPath` 计算 `d`（同一流坐标系，无需换算视口；端点位置回退规则同源码 `Top`/`Bottom`），模板渲染 `path` 并绑定 `d` 与固定类名，配色/线宽/光晕在 scoped 样式 `.canvas-connection-preview` 单一来源定义（插槽内容渲染在 `AssetCanvas` 自身模板内，scoped 属性直接命中，无需 `:deep`）。**仅高亮预览线本身**：不改变既有连线高亮（单选联动、运行态、改接虚线）派生集与样式，也不额外描边端点或邻接节点；`Esc` 不取消连线预览（Vue Flow 原生行为——库未为普通连线拖拽注册 `Esc`，应用侧仅「连线改接」自绘覆盖层支持 `Esc`，本次改动不改变该行为）。
- **连接转移 / 连接复制（批量改接，`useCanvasRewire` + `store.rewireConnections`）**：
  - **连接转移**：按住 `Shift` + 左键在节点端点上按下，把输入/输出该端点的**全部连线「拔出」**（拖拽中原线虚线半透明，实际保留在 store，取消零丢失），跟随鼠标（SVG 预览曲线 + 「N 条连线 · 转移」徽标），在**另一节点**的同类型端点上释放后批量改接；**连接复制**：`Ctrl` + 左键，操作一致但原线保留、仅新增（原线无虚线样式）；`Shift` 与 `Ctrl` 同按时转移优先；
  - **方向限定**：输入端起点只能落到输入端（改去向），输出端起点只能落到输出端（改来源）；落到空白/方向不匹配静默取消，落到同节点端点气泡「无效目标」，`Esc` 取消；
  - **校验与部分成功**：逐条按「节点级重复（同一来源节点对同一目标节点已存在任意连线即忽略）/ 类型兼容 / 成环」校验，通过者批量改接（**单次撤销**快照，同步两侧 `config.inputOrder`：源端移除条目、目标端按新连线建立顺序追加），失败者保持原位；结束后 snackbar 汇总（全部成功 / 部分成功含跳过原因计数 / 全部忽略）；
  - 实现：mousedown 在 flow 容器 **capture 阶段**拦截（阻止 Vue Flow 原生单线拖拽与 Ctrl 框选；端点上无连线时不拦截、维持原生行为），落点识别用 `document.elementFromPoint` 找 `.vue-flow__handle`（读自带 `data-nodeid`/`data-handleid` 与 `source`/`target` class），拖拽中悬停端点实时校验并标记可落（绿）/不可落（红）高亮；拖拽结束吞掉一次 click 防误选中。
- 断开连线：
  - 右键连线 → 「断开连接」（`@edge-context-menu`，需 `event.preventDefault()` 阻止浏览器默认菜单）；
  - 右键节点 → 「断开连接」（断开该节点全部连线）；
  - 选中连线后按 `Delete`；
  - **编辑器/节点输入缩略图右上角红色 x → 快捷断开该输入**（生成图片/生成视频/拼接视频/AI文本生成节点）：悬浮缩略图时显示，点击即断开该来源节点→本节点的连线并同步清理 `config.inputOrder` 中该来源 id（`nodeOps.disconnectInput` → `store.disconnect` + `removeInputOrderEntry`，两者合并为单次撤销，Ctrl+Z 可整体恢复；生成视频节点经 connectionSync 自动移除导演台对应素材块）。

## 画布交互

| 交互 | 行为 |
|------|------|
| 点击节点 | 选中 + 显示配置面板（有 editorComponent 时）；**多选下普通单击切换为仅选中该节点** |
| 单选联动高亮（选中 1 个节点时） | 与该节点**直接相连**的全部连线（选中节点作 source 或 target）按**方向分色**并加粗（2px）：输入侧（指向选中节点）= 绿色 `#2E7D32`，输出侧（选中节点发出）= 橙色 `#EF6C00`（`useCanvasFlow` 按单选集在连线上挂 `canvas-edge--related canvas-edge--input/output` class，颜色经 `--edge-related-color` CSS 变量单一来源，样式见 AssetCanvas `:deep` 规则）。关联连线叠加**沿数据流向**移动的箭头动画（`#edge-default` 插槽：与 `BezierEdge` 完全相同的参数经 `getBezierPath` 计算连线 d，注入箭头 `offset-path: path(...)`，`offset-rotate: auto` + `@keyframes canvas-edge-arrow-flow` 驱动 `offset-distance` 0%→100%——连线路径由 source→target 生成，方向天然即数据流：输入侧箭头从邻接节点流向选中节点，输出侧反向；未关联连线无箭头）。**箭头动画的时长与数量按连线弧长推导（恒定线速度 + 等距多箭头）**：`offset-distance` 是弧长百分比，若时长写死则线速度 = 弧长/时长 会随长度线性增长（长连线箭头快到肉眼无法观察），故由 `canvas/edgeFlow.ts` 解析贝塞尔弧长后给出 `duration = max(弧长/110px·s⁻¹, 0.8s)`、`count = clamp(round(弧长/220px), 1, 6)`、`delayStep = duration/count`（相邻箭头以负 `animation-delay` 等距预分布），模板 `edgeArrows()` 为每条高亮连线渲染 `count` 个箭头并内联写入 `animation-duration`/`-delay`——长短连线视觉速度一致（≤110 流坐标 px/s）、箭头密度一致，超长连线靠多箭头而非加速；端点 4% 弧长淡入淡出消除循环回绕跳变，`prefers-reduced-motion: reduce` 下箭头静止于连线中点（`offset-distance: 50%`）。`createEdgeFlowCache` 按连线 id 记忆参数：拖动/缩放节点时弧长每帧变化，弧长变化 <15% 且箭头数量未跨档则复用旧时长，避免箭头跳位（几何仍每帧更新，箭头平滑跟随路径）。连线另一端点（1 跳邻接节点，剔除选中节点自身）按方向分色描边（`CanvasNodeCard` 的 `canvas-node--adjacent-input/output`：输入绿 `#2E7D32` / 输出橙 `#EF6C00`，半透明外圈、**弱于选中态**，与选中/成组拖拽悬停同现时后两者优先）。纯前端派生：无选中/多选（≥2，群组操作模式）时不高亮；清空选中、切换分镜/场景自动消失。**数据源**：应用级 `selectedNodeIds` 单选（点击/框选/粘贴聚焦/**单节点拖动聚焦**均写入），拖动单节点时高亮随拖动实时出现 |
| 运行态高亮（节点 Loading 时） | 节点 `statusByNode[id].status === 'running'`（工作流/ffmpeg/AI 文本统一状态机，刷新/切画布经 restore 恢复后同样生效）时：① 运行节点自身主色蓝 `#1976D2` 边框 + **脉冲呼吸外圈**（`CanvasNodeCard` 的 `canvas-node--running`：`@keyframes canvas-node-running-pulse` box-shadow 2px↔4px 循环，区别于静态选中边框，与选中态同现时脉冲胜出）；② **1 跳上游节点**（直接供数节点）主色弱描边（`canvas-node--running-adjacent`，半透明外圈、弱于选中态，节点自身 running 时让位）；③ **输入连线**（指向运行中节点）主色蓝加粗并叠加与单选联动高亮**共用**的沿数据流向箭头动画（时长/箭头数量同样按连线弧长推导，恒定线速度 + 等距多箭头，见上一行）（`useCanvasFlow` 的 `runningInputEdgeIds/runningInputNodeIds` 派生集；连线挂 `canvas-edge--related canvas-edge--running` class，颜色经 `--edge-related-color: #1976D2` 变量提供，与单选联动高亮互斥时 **running 优先**）。任务终态（成功/失败/中断）自动消失；上传进度态不属于运行态高亮范围 |
| `Ctrl`+点击节点 | 增/减选该节点（多选） |
| `Ctrl`+空白处左键拖动 | **框选多个节点**（Vue Flow 内置框选：selectionKeyCode/multiSelectionKeyCode 经 `setState` 写入 `Control`，避免运行时 prop 类型告警；`selection-mode` 为 Partial——**与节点存在交集（无需完全覆盖）即选中**）；框选结束（`@selection-end`）后应用级多选与 Vue Flow 内部选中态双向同步 |
| 多选（≥2 个节点） | 显示**群组虚线框**（合成节点 `__group-frame`，位于节点下层，与边缘节点保留 12px 流坐标留白 `GROUP_FRAME_PADDING`）+ 右侧垂直居中的**输出连接圆点**（合成节点 `__group-dot`，位于全部节点上层）。原生多选包围框被样式隐藏（避免覆盖节点点击），由合成节点替代 |
| 拖动群组虚线框 | **整体移动全部选中节点**（框架节点 `draggable`，Vue Flow 原生拖动携带全部选中节点；结束经 `store.updateNodes` 单次撤销快照批量回写） |
| 右键群组虚线框 | 组菜单：复制 / 删除（删除整组一次确认） |
| 群组输出圆点拖拽 | 从圆点拖出预览虚线（SVG）→ 悬停目标节点高亮（绿色描边）；释放：① 命中其他节点（流坐标包围盒命中）→ **成组连接**（类型兼容/成环/目标在组内/重复连线逐源校验，失败源忽略 + snackbar 气泡提示原因）；② 未命中任何已有节点（拖拽位移 > 6px 最小判定，区分点击圆点）→ 弹出「选择目标节点」菜单（全部有输入端口的原型：生成图片/生成视频/TTS/获取视频帧/拼接视频/裁剪视频，按群组输出类型兼容性过滤，不兼容项置灰并注明原因），选中后在释放点创建该节点并把全部兼容源连接到新节点输入口（不兼容源忽略 + 气泡提示），随后单选新节点（不自动弹配置面板）；③ 位移 ≤ 6px（视作点击圆点）→ 取消 |
| **多选（节点数 + 分组数 ≥ 2）悬浮工具栏** | 多选框**顶部居中**悬浮（顶部空间不足时翻转到多选框下方；横向钳制在画布内），含「创建分组」按钮（`nodrag` + `mousedown.stop`，点击不触发画布 pan/框选/pane-click）。**选中集包含分组时按钮置灰**并提示「选中集已包含分组」（避免框套框） |
| **点击「创建分组」** | 以选中节点包围盒 + 左右/下 12px 留白 + **顶部额外 28px 标题条留白**（顶部合计 40px，保证最上方节点不被标题条压住）创建持久分组（最小 160×100），默认标题 `分组 N`（N 为最小未占用编号）、默认色为色板首色蓝 `#1976D2`；创建后**保持多选**，snackbar 提示「已创建分组「分组 N」（含 M 个节点）」；单次撤销 |
| **`Ctrl`+拖拽完全框选分组框** | 框选矩形**完全包含**分组矩形（容差 2px）→ 该分组进入选中集；**仅相交不选中**。完全包含时其成员节点必然同时被 Vue Flow 的 Partial 模式选中（成员节点与分组矩形重叠 ⇒ 必与框选矩形相交）。框选会**替换**分组选中集（与 Vue Flow 框选替换节点选中一致） |
| **拖动持久分组标题条 / 四边拖动条** | 分组框与**跟随集**（R2：与分组矩形重叠的节点 + 被该分组**完全包含**的其他分组，递归收敛、节点去重）整体平移，相对位置不变；拖动内层分组**不带动外层分组**；不读取也不修改节点选中态；位移 < 4px 视作「点击」→ 选中该分组；单次撤销 |
| **按住 `Ctrl` 在分组标题条 / 边框上拖拽** | 穿透为框选（分组节点整体 `pointer-events: none` → 指针命中 pane）——「Ctrl+拖拽 = 框选」零例外 |
| **单击分组标题条 / `Ctrl`+单击** | 单选该分组（**清空节点选中**）/ 增选、减选；单击节点或空白处清空分组选中 |
| **双击分组标题条** | 内联重命名（回车/失焦提交、Esc 取消、空名放弃）；标题条右侧**色点按钮**打开 8 色预设色板，选色后标题条（90%）/ 填充（8%）/ 边框（70%）三处同步变色；各自单次撤销 |
| **右键分组框** | 菜单：重命名 / 更改颜色 / 解散分组（解散弹 `confirm` 确认，**仅删框、组内节点保留**） |
| **选中/悬浮分组后拖拽八向控制点** | 缩放分组框（最小 160×100，缩放中控制点保持可见）；**组内节点不跟随移动/缩放**；缩到与某节点不再重叠时该节点自动脱离（成员派生）；结束才回写 store，单次撤销 |
| **空分组** | 标题条显示「空」标记 + 整体不透明度 0.55（提示已被拖空，**不自动删除**） |
| **拖动节点进出分组** | 自动加入 / 脱离（成员关系由几何重叠实时派生，无显式操作） |
| 双击节点名称 | 内联重命名（回车/失焦提交、Esc 取消、空名放弃） |
| 拖拽节点 | 移动位置，结束回写 store（防误触：拖拽中隐藏配置面板）；**被拖动的真实节点恰好 1 个时进入「拖动聚焦」**：拖动开始即把应用级选中切为**单选**该节点（`useCanvasSelection.focusNodeForDrag`），使其输入/输出关联高亮（连线分色 + 流向箭头 + 邻接节点描边）在拖动过程中实时出现，且**不弹出配置面板**；拖动结束保持选中（Delete/复制等快捷键可用），再次**单击**该节点才打开面板。**多选整组拖动**（≥2 个真实节点，含拖动群组虚线框）不改变选中集、不高亮，整组移动语义不变；**拖动选中节点时 Vue Flow 原生把全部选中节点一起移动**（结束批量单次撤销） |
| 悬浮/选中节点后拖拽边缘或四角 | 调整节点大小（**全部节点类型**可缩放，最小 120×80px，`@vue-flow/node-resizer` 渲染控制点；缩放中控制点保持可见，结束才回写 store） |
| 右键节点 | 菜单：重新生成 / 历史 / 保存为（hover 子菜单：角色设计 / 角色设计-衍生变体 / 场景图 / 场景图-衍生变体 / 自定义资产，仅输出类型为图片且有产物的节点显示）/ 断开连接 / 重命名 / 复制 / 删除（删除需 `confirm` 确认）。**右键节点时切换为单选该节点** |
| 右键连线 | 菜单：断开连接 |
| 单击连线 | **选中该连线并主题色高亮**（`#1976D2` + 2px 加粗 + 同色光晕，与拖拽中的连线预览线**同一视觉处理**，表示「这条线正处于操作焦点」；**不叠加流向箭头**——箭头语义是「数据正在流经」，属运行态/单选联动高亮，单击选中加箭头会被误读为正在生成）。同时写入 `selectedEdgeId`（驱动 Delete 断开与右键断开）。**不改变节点选中**（连线关联高亮与节点关联高亮是两套独立派生集，可同屏并存）；点击**节点**或**空白**会清空连线选中。class 优先级：运行态 > 改接虚线 > 单击选中 > 单选联动（同名连线仅挂一个 class，互斥不叠加），见 `useCanvasFlow` 的 `flowEdgeList` |
| 单击空白 | 取消选中（节点 + 分组 + 连线）、关闭菜单 |
| 双击空白 | 在鼠标双击处弹出「添加节点」VMenu（**三列分类：加载 / 生成 / 工具**，按 registry `category` 分组；选择节点原型后在该处添加节点） |
| 右键空白 | 弹出「添加节点」VMenu（`paneContextMenu` + `preventDefault`），节点落在右键点击处；与双击同一菜单（三列分类，见上），不改变当前多选状态 |
| 从资产浏览器拖拽资产到画布 | 左侧资产浏览器仅「角色 / 子场景 / 道具」可拖（目录/分类/根节点不可拖）；拖入画布释放后**在释放位置**弹出资产菜单：图片/音频/视频**各占一行**（媒体标签 + 横向滚动的资产条目：图片缩略图 / 音视频试听组件 + 条目名，条目溢出时行内横向滚动；实体无对应资产的行隐藏），点条目名（图片亦可点缩略图）在释放位置创建对应**加载图片 / 加载音频 / 加载视频**节点（`config.assetPath` 绑定该资产，单次撤销），命名规则见下文 |
| 适应视图 / 放大 / 缩小 | 工具栏按钮（`fitView` / `zoomIn` / `zoomOut`）；适应视图按全部节点包围盒居中并缩放落入可视区（padding 0.2、maxZoom 1，不放大超过 100%） |
| 滚轮 | 空白/节点上滚动 = 缩放画布；文本节点文本域上滚动 = 滚动文本（`nowheel` 类豁免缩放） |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做（输入框聚焦时跳过） |
| `Ctrl+C` / `Ctrl+D` | 复制选中节点（1 个或多个，**含组内连线**）到画布内部剪贴板，并同步把「节点复制标记 + JSON」写入系统剪贴板（覆盖剪贴板旧内容，与主流节点编辑器复制语义一致；无剪贴板 API 时静默降级为仅内部剪贴板） / 复制粘贴（重复节点/整组） |
| `Ctrl+V` | 粘贴剪贴板内容，按类型分派：**画布内复制的节点标记 → 粘贴节点（单/多节点，最高优先级，不会被剪贴板中残留的旧文本/文件抢占；也支持跨画布/刷新后粘贴，节点 JSON 从系统剪贴板解析；多节点粘贴**重建组内连线，并重映射 `config.inputOrder` 与导演台素材块 `sourceNodeId`**）**；图片/视频/音频文件 → 上传到 `assert/custom/canvas/` 并创建对应加载节点（可视区中心错位摆放）；文本 → 创建文本节点并写入文本；剪贴板为空不派发 paste 事件时由 keydown 兜底粘贴内部复制的节点。粘贴的新节点**自动聚焦**（全部选中，显示可调整大小的边框与缩放控制点，应用级选中使 Delete/复制快捷键可用），且**不自动打开配置面板**（仅用户点击节点才打开） |
| `Delete` / `Backspace` | 删除选中节点（1 个显示节点名、多个显示数量，均 `confirm` 一次确认；整组删除单次撤销）或选中连线 |
| `Esc` | 关闭右键菜单 / 取消内联重命名 |
| 节点处于 loading（`status = running`） | **通用能力**：`CanvasNodeCard` 在节点内容上叠加半透明遮罩 + 加载动画 + 最近日志 + 「中断」按钮（统一中断入口）；error 时叠加错误遮罩 + 「重试」。运行态由**服务端统一任务注册表**驱动（ffmpeg/LLM 经 WS 广播、工作流本地轮询），离开画布/刷新后未完成任务继续显示 loading（见 [task-architecture.md](./task-architecture.md) / [generation.md](./generation.md)） |
| 加载节点上传文件（「上传图片/音频/视频」按钮或粘贴媒体） | **节点内上传进度条（通用能力，`useCanvasUpload` 状态驱动）**：上传中节点卡片叠加进度遮罩（文件名 + `v-progress-linear` + 百分比/已传大小，总大小未知时显示不确定进度条）；失败时叠加错误遮罩（错误文案 + 「重试」按钮，沿用原文件与目标路径重传）+ snackbar 提示，遮罩 8s 后自动消失；成功遮罩消失、节点立即展示新资产。粘贴媒体先创建空加载节点再逐个上传（进度显示在各节点上，全部完成后 snackbar 汇总），上传失败保留空节点可直接重试/选资产 |

> Vue Flow 绑定注意：勿用 `v-model:nodes/edges` 绑 computed（会报 readonly 写入错误），用单向 `:nodes/:edges` + `@node-drag-stop` 回写 + `@edges-change`(remove) 同步删除。

## 持久分组（节点分组框，`canvas/groups.ts` + `useCanvasGroups` + `CanvasGroupNode.vue`）

> 与上文「群组虚线框」的区别：虚线框（合成节点 `__group-frame` / `__group-dot`）是**一次多选操作的临时视觉反馈**（不入 `canvas.json`）；持久分组是**可持久化的可视化容器**（写入 `canvas.json` 的 `groups[]`，见 [data-model.md](./data-model.md#持久分组groups)）。两者**并存**，虚线框与输出圆点的成组连接行为完全不变。

**成员判定（核心规则）**：节点矩形与分组矩形**重叠面积 > 0** 即视为组内成员，**相切（边贴边）不算**；成员关系**不落盘**，每次由几何实时派生。推论：

- 拖动节点进入分组矩形 → 自动加入；拖出 → 自动脱离；
- 一个节点可**同时属于多个重叠分组**；
- 缩放分组框使其与某节点不再重叠 → 该节点自动脱离；
- 两个分组**部分重叠**时，重叠区节点会跟随被拖动的那一个离开另一个（几何必然，非缺陷）。

**拖动跟随集（R2）**：拖动分组时，跟随平移的是「与跟随集中任一矩形重叠的节点」∪「被跟随集中任一矩形**完全包含**的其他分组（递归收敛，节点去重）」。可证明性质：若 B ⊆ A，则 B 的任意成员节点必与 A 重叠 ⇒ 嵌套结构在拖动中保持完整，不会留下被掏空的空框。拖动内层分组时，外层分组不满足「被内层完全包含」，因此不动。

**创建几何（标题条留白）**：`groupRectFromNodes(nodes, padding, topInset)` 的顶部留白 = `padding + topInset`，创建分组传 `GROUP_FRAME_PADDING`（12）+ `GROUP_HEADER_HEIGHT`（28）= 40px，左右/下为 12px，保证组内**最上方节点顶边不会被顶部标题条压住**。标题条高度只有一处定义（`groups.ts: GROUP_HEADER_HEIGHT`），`CanvasGroupNode.vue` 经 CSS 变量 `--canvas-group-header-height` 引用（标题条高度与顶部拖动条 `top` 都取自该变量），改常量即可同步生效；未达最小尺寸 160×100 时的对称扩张只会让矩形上边缘继续上移，顶部间距**恒 ≥ 40px**。

**实现约束（Vue Flow 源码级，改动前必读）**：

| # | 约束 | 原因 |
|---|------|------|
| 1 | 分组节点 wrapper **必须** `pointer-events: none !important`（仅标题条 / 四边拖动条 / 缩放控制点 `auto`） | 框选要求指针按下时 `event.target` 恰为 `.vue-flow__pane`；Vue Flow 会为带节点点击监听的节点内联 `style="pointer-events: all"`，普通样式规则压不过内联样式，故需 `!important`。否则**组内框选完全失效** |
| 2 | 分组节点 `selectable: false` | 框选实现会跳过不可选中节点 ⇒ Vue Flow 内部选中集永远不会含分组；「完全框选选中分组」由 `useCanvasGroups.onSelectionEnd` 自行判定（`userSelectionRect` 在 `selectionEnd` 事件前已被置空，只能由 `selection-start` / `selection-end` 的指针事件换算选框矩形） |
| 3 | 分组节点 `draggable: false` + 自定义拖动 | 原生拖动会同时移动**全部选中节点**；若分组用原生拖动，在有节点被选中时会「移动两次」。自定义拖动：`mousedown` 记录跟随集与原始坐标 → window `mousemove` 经 `updateNode(id,{position})` 命令式移动（**不写 store**，连线实时跟随）→ `mouseup` 经 `store.moveEntities` 一次性回写（单次撤销） |
| 4 | 分组节点尺寸经 `style` 下发（而非 `width`/`height` 字段） | NodeResizer 缩放时会写入内部节点 `style`；若我们的节点对象不带 `style`，store 回写（缩放结束/撤销）后内部 style 残留旧尺寸，框体渲染尺寸与数据不一致 |
| 5 | 分组节点 `class` 用**函数**按 Ctrl 状态挂 `canvas-group-node--passthrough`（函数体内读 `ctrlHeld`） | `class` 支持 `string \| ((node) => string)`，由 NodeWrapper 的 computed 求值；把 Ctrl 读取放在函数体内部，`flowGroupNodeList` computed **不依赖** Ctrl 状态，避免按键时重建整个节点列表 |
| 6 | 分组节点列表只依赖 `store.groups`（不依赖 `statusByNode` 等高频状态） | 轮询期间重建节点列表会导致节点/连线动画重置（见 [development.md](./development.md) 常见坑） |
| 7 | 拖动结束的合成 click 用「一次性捕获阶段拦截器」吞掉 | 释放点落在画布空白处时，浏览器补发的 click 会命中 pane 触发 `pane-click`，清空刚选中的分组（与成组连接输出点拖拽同一手法） |

**多选拖动时分组跟随**：拖动已选中节点（原生拖动）时，若选中集含分组，则这些分组按被拖节点位移经 `updateNode` 同步移动；拖动结束 `AssetCanvas` 先取分组位置补丁，再与节点位置一起经 `store.moveEntities` **一次**回写（单次撤销）。

**拖动 / 缩放 / 重命名的撤销粒度**：拖动与缩放过程中**不写 store**（仅视图跟随），结束时一次性回写；因此 Ctrl+Z 一次即可整体回退。

## 从资产浏览器拖拽资产到画布（`canvas/assetDrop.ts` + `useCanvasAssetDrop` + `CanvasAssetDropMenu`）

**可拖拽范围**：资产浏览器「角色 / 场景 / 道具」分支下的**叶子节点**（角色、子场景、道具）可拖入画布；目录/分类/根节点（角色分类、道具分类、场景父节点、集数分镜、剧本、自定义资产等）不可拖。树内既有拖拽（角色分类调整、分镜移动）行为不变。

**交互流程**：

1. 拖拽开始：`AssetTree.onDragStart` 对角色/子场景/道具写入模块级共享载荷 `canvasDragPayload`（`assetDrop.ts` 的模块级 ref，`dataTransfer` 同步写入自定义 MIME `application/x-canvas-asset` 作备份）；
2. 拖到画布：`AssetCanvas` 在 flow 容器 `dragover` 中校验载荷 → `preventDefault()` 允许 drop + 画布主色虚线描边高亮（`asset-canvas__flow--asset-drag`）；
3. 释放：drop 经 `screenToFlowCoordinate` 换算**释放位置**为流坐标 → `useCanvasAssetDrop.openAt` 在释放位置弹出菜单（0×0 锚点 + `v-menu`，同添加节点菜单定位手法）并异步构建媒体分组（loading 态）；
4. 菜单布局（单层）：图片/音频/视频**各占一行**（实体无对应资产的行隐藏），每行 = 左侧媒体标签（图片/音频/视频）+ 右侧横向滚动的资产条目（缩略图/试听组件 + 条目名，条目溢出时行内出现横向滚动条；整菜单高度超限时纵向滚动）；
5. 点击条目：点条目名行（图片亦可点缩略图）按媒体类型创建`加载图片 / 加载音频 / 加载视频`节点，`config.assetPath = 资产路径`，节点**以释放点为中心**摆放（减去原型 defaultSize 一半），名称按命名规则写入（与创建同一次撤销，Ctrl+Z 整体回退），不自动打开配置面板。

**命名规则**（基础资产菜单显示名 = 实体名、节点名 = 实体名；变体菜单显示名 = 变体名、节点名 = `实体名-变体名`）：

| 实体 | 资产 | 菜单显示名 | 节点名 |
|------|------|-----------|--------|
| 角色 | 外观图 `appearance.jpg` | `角色名` | `角色名` |
| 角色 | 衍生变体 `variants/{id}(/…).jpg` | 变体链名（父-子，单层即 id） | `角色名-{变体链名}` |
| 角色 | 基础音色 `voice.{ext}` | `角色名` | `角色名` |
| 角色 | 声音变体 `voice-variants/{id}.{ext}` | 变体 id | `角色名-{id}` |
| 子场景 | 基础场景图 `assert/stage/{场景}/{标签}.jpg` | `{子场景标签}` | `{子场景标签}` |
| 子场景 | 衍生变体 `variants/{标签}/{id}(/…).jpg` | 变体链名 | `{子场景标签}-{变体链名}` |
| 道具 | 固定产物 `image.jpg` / `audio.flac` / `video.mp4` | `道具名` | `道具名` |
| 道具 | 其它上传文件（可多个） | 文件名（含扩展名） | `道具名-{文件名主干}` |

**资产列举规则**（`loadCanvasDropMenuGroups`）：

- 存在性判定用 `existsFs`（外观图/基础场景图/基础音色实际路径）；衍生变体仅列出**已生成**（`hasImage`/`hasAudio`）的条目，多级变体按父链深度优先排序（`orderVariants`），命名用父子链名（`variantChainName`）；
- 道具按媒体类型递归列举 `assert/prop/{分类}/{道具}/` 下文件，固定产物排在首位；分类内读取失败降级跳过该媒体类型并向控制台输出日志（不影响其余分区）；菜单打开期间加载失败 → snackbar「加载资产列表失败」+ 空态；
- **边界**：仅标准资产 + 衍生/声音变体，不含实体「自定义资产」（`assert/custom/...`）与分镜产物 —— 这些仍走加载节点右侧资产选择器。
