# 前置设定

在进入具体内容设计之前，先通过问答方式引导用户确立项目的顶层定位。

**流程规范：**

1. 从用户给出的需求描述中提取已知信息，对仍有多个可能性或不确定的项，通过 `question` 或 `ask_user` 工具让用户做选择
2. 每个问题应提供 2-3 个明确选项，选项需有清晰差异和简短说明，让用户能快速决策
3. 需引导用户确认的决策点按以下顺序逐一询问：

## 决策顺序

以下决策点按顺序推进，但每个决策的**选项内容不局限于文档中列举的例子**，根据用户需求发散创作：

1. **目标受众** — 明确视频的目标观众群体
   - 影响：内容复杂度、叙事节奏、主题深度
   - 根据项目题材发散：不限于"年龄段"划分，也可以是特定兴趣群体、职业群体等

2. **情感基调** — 故事的整体情绪底色，不同段落可有变化
   - 影响：所有后续设计的情绪导向
   - 可单一可混合，不限于常见标签，根据题材发散创作

3. **色彩基调** — 整体视觉的色彩倾向
   - 影响：指引后续所有场景的主色调设计
   - 可结合情感基调发散，也可以抽象概念表达（如"旧照片的黄"、"廉价日光灯的冷白"等）

4. **美术风格** — 视觉表现风格
   - 影响：角色设计、场景渲染的方向
   - 可结合AI模型能力发散，不局限于常见风格标签

5. **画面比例与分辨率** — 视频的横竖屏格式和分辨率
   - 影响：场景构图方式、角色在画面中的位置设计、文字排版空间
   - 常见选择：
     - 横屏 16:9（1920×1080 或 1280×720）— 适合PC/电视播放，故事感和电影感强
     - 竖屏 9:16（1080×1920 或 720×1280）— 适合抖音/快手/小红书等短视频平台
     - 方形 1:1（1080×1080）— 适合社交平台信息流
   - 不限于上述常见选择，可根据发布平台发散

> 用户选定画面比例与分辨率后，依次运行以下命令写入 `project.json`（项目属性脚本，与分镜 JSON 工具同属 `scripts/`；分镜相关工具见 [`04-script-tools.md`](./04-script-tools.md)）：
> ```bash
> python .claude/skills/create-video-script/scripts/set_project_property.py --project "{项目名称}" aspectRatio "{用户选择的比例}"
> python .claude/skills/create-video-script/scripts/set_project_property.py --project "{项目名称}" width {画面宽度}
> python .claude/skills/create-video-script/scripts/set_project_property.py --project "{项目名称}" height {画面高度}
> ```

6. **剧情方向** — 在确定以上基调后，准备 2-3 个不同的剧情概念方向供用户选择
   - 每个方向需包含一句话梗概和核心看点说明
   - 方向之间应有明显差异，覆盖不同切入点
   - 用户选定后进入剧情细化

其他决策：根据用户的回答你需要再提问1到2个你认为需要考虑或建议的决策方向
