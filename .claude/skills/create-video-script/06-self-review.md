# 输出自我审查

> **自动化校验优先：** 审查前先运行 [`validate.py`](./04-script-tools.md#完整性校验)（可加 `--fix` 尝试自动修复），再由子 Agent 对照下列清单做人工复核。脚本参数与校验范围见 [`04-script-tools.md`](./04-script-tools.md)。

派出一个干净的子Agent（Sub-Agent），检查本次输出产生的prompt资产是否满足以下约束：

- 非外国角色或地名的资产文件夹名称是否为中文
- 场景或角色提示词原型中是否包含对 AI 绘图模型不必要的描述（如人名、文件头元数据）
- 项目 `design/` 下每个项目目录是否包含 `overview.md`（用于脚本自动检测）
- 分镜 `overview.json` 是否存在，字段齐全，`duration` 为 `> 0` 的整数；不得残留分镜 `overview.md`
- 分镜 `stage.json` 中 `基础场景` 是否非空：普通引用须在 `design/{项目}/prompt/stage/` 下有对应 `.md`/变体；关键字 `prev` 须当前分镜 > 1 且同集上一分镜 `stage.json` 非空
- 分镜 `stage.json` 中：若 `登场角色` 与 `prompt` 同时为空，是否为有意的「直接引用」（基础场景或 `prev`）；`prev` 不得叠加角色/prompt；否则 `prompt` 不得为空，且有角色时角色资产目录须存在
- 分镜 `stage.json` 中引用的 `登场角色` 是否在对应项目的 `design/{项目}/prompt/character/` 下有对应的资产文件夹
- 分镜 `stage.json` 中 `登场角色` 数组长度是否不超过 2
- 分镜 `stage.json` 中非直接引用时，`prompt` 字段是否正确使用"图像1"代表基础场景、"图像2"代表第一个角色、"图像3"代表第二个角色。不应对基础场景和人物外貌设计中已有的描述重复。（如：人物外貌设计中已经说明了人物穿了什么衣服，拿着什么东西，那么 `stage.json`的`prompt` 中就不要重复这部分描述）
- 分镜 `stage.json` 中有 `登场角色` 时，`prompt` 是否写清：**人物与人物（或人物与场景地标）的位置关系**；以及**面部与身体朝向**，且朝向以人或场景特征为参考点（禁止无锚点的抽象方位）
- 分镜 `script.json` 中出现的 `角色名` 是否在对应分镜的 `stage.json` 的 `登场角色` 中已声明
- 分镜编号是否从 1 开始且连续无跳号（按集分别校验）
